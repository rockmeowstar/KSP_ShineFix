HLS Project 0.4

HLS Nose Cone. The four source emission islands and two photovoltaic atlas islands define independent grayscale masks. The stock Mk3 crew cabin IVA stays in the author position. The glass and hull cutout share the reflection mask on NOSE.004. Reflective finish is 0.95 with #e7e7e7. Nearby glass uses 80% opacity and half of the author window emission. The fixed cells bind separately on the default renderer with all 12 native photovoltaic modules present.

KSP rendered each of the four panes with and without the actual IVA in each scene. The mean pixel difference per pane was 29.58?31.88 RGB in the SPH and 32.20?40.39 on the runway. The native light switch changed state in flight. The one-part craft assigns five of the ten native seats. The close camera was used to verify the base opacity because the runtime fades exterior interiors with distance.
